### Claude Code v2.1.232 发布：子代理 Fork 默认开启及会话间提及

- **发生了什么**：Claude Code v2.1.232 将子代理的 Fork 模式设为默认，并引入了通过 `@` 符号在会话间提及和交互的能力。
- **背景**：为了提升复杂任务的处理效率和用户体验，Claude Code 对其内部的子代理（subagent）机制进行了重大默认配置调整，并引入了新的会话交互模式。
- **证据**：官方 Release 说明：`subagent_type: "fork"` 子代理现在默认继承完整对话和提示缓存；非团队成员代理在交互会话中默认后台启动；新增 `@` 提及功能。来源：GitHub Release v2.1.232。
- **分析**：默认开启 Fork 子代理意味着更倾向于上下文共享和缓存，这能减少重复计算，提高响应速度，尤其是在相关联的子任务间。后台运行则改变了交互节奏，避免主线程阻塞。会话间提及是协作模式的初步探索，为构建更复杂的多代理工作流奠定了基础。
- **影响**：直接改变用户的操作习惯和预期。用户无需手动设置即可享受上下文继承带来的便利，但也需适应子代理后台运行的模式。`@` 功能是强大的上下文管理工具，尤其适用于智能诊断等需要关联历史信息的场景。
- **建议行动**：无需立即行动，但需主动适应。测试 Fork 子代理在后台运行的效果。规划如何利用 `@` 功能来组织和链接你的开发、诊断或信息收集会话。
